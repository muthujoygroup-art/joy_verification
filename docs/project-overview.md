# JOY TRUE PROFILE — Project Overview

## 1. Executive Summary
**JOY TRUE PROFILE** is an enterprise-grade digital workforce verification and profile management platform engineered by **JOY CORPORATE SOLUTIONS PRIVATE LIMITED**. The platform enables organizations, human resource teams, and workers to create, manage, and verify workforce profiles through unified, connected digital workflows with high speed, data security, and compliance.

## 2. Core Business Problem
Modern workforce management—especially for fast-scaling contractors, blue-collar workers, and IT professionals—suffers from:
1. **Slow Onboarding Timelines**: Traditional background verification (BGV) takes 7 to 21 days, delaying critical hiring surges.
2. **Ghost Workers & Duplicate Billing**: Lack of instant biometric deduplication leads to fraudulent contractor billing and phantom workers on factory muster rolls.
3. **Moonlighting & Overlapping Tenures**: Multiple active EPFO records go unnoticed without real-time service history audits.
4. **Frictional Worker Experience**: Complex apps and physical paperwork lead to high candidate drop-offs.
5. **Data Privacy Risks**: Handling unmasked Aadhaar cards and PAN scans violates statutory DPDP Act 2023 guidelines.

## 3. The Joy True Profile Solution
Joy True Profile solves these challenges through:
- **Zero-App Candidate Verification**: Candidates receive a secure, PIN-protected verification link via WhatsApp, SMS, or Email that runs in any mobile browser in under 2 minutes.
- **Direct Rails Verification**: Automated checks across government identity, PAN, EPFO career records, and bank penny drop validation.
- **CLRA Form XVI & Gate Pass Compliance**: Automatically generated digital QR gate passes and tamper-proof PDF audit dossiers.
- **100% Postpaid Enterprise Billing**: Companies verify on-demand and settle monthly with automated GST tax invoices.

## 4. Key Stakeholders & Portals
- **SuperAdmin**: Full platform control, provider routing, master data management, system telemetry, and company plan management.
- **Company Admin**: Organizational hierarchy, HR recruiter allocation, labor quota tracking, CLRA reports, and postpaid ledgers.
- **HR Executive**: Candidate profile creation, Excel bulk import (500+ records in 10s), multi-channel link dispatching, and 360-degree verification dossier review.
- **Candidate / Worker**: 2-minute mobile self-verification, OTP-based consent, document checks, and digital gate pass access.

## 5. Technology Stack
- **Frontend**: React 19, Tailwind CSS v4, Lucide Icons, Vite, HTML5 Canvas Confetti, Three.js.
- **Backend**: Python FastAPI, SQLAlchemy 2.0, Pydantic v2, Uvicorn, Python-Multipart.
- **Database**: PostgreSQL 16 (with SQLite fallback for zero-downtime local execution).
- **APIs & Connectors**: Sandbox.co.in, CoinCircleTrust / Neev 81 APIs, WhatsApp Cloud API, cPanel SMTP.
